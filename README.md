## 把“高性价比”拆成三个能比较的数

**第一个数是带宽上限。** 100Mbps 的机器，理论上下行约 12.5MB/s，一个人看 4K 够用，三个人同时拉文件就开始排队。300Mbps 约 37.5MB/s，1Gbps 约 125MB/s。所谓“高峰期不慌”，说的就是晚高峰三家运营商都在抢资源的时候，你这台机器还有余量把数据推出去、拉回来。带宽上限低于 300Mbps，谈性价比的意义不大，因为你买到的是一台平时够用、忙时难受的机器。

**第二个数是线路质量。** 这一项最容易被“XX 线路”的名词糊弄过去，实际拆开只有几件事：

| 名词 | 它实际影响什么 |
| --- | --- |
| CN2 GIA | 电信的高质量国际通道，回程不走普通公网，晚高峰掉速幅度小，价格也最贵 |
| AS9929 | 联通精品网，回程质量接近 CN2 GIA，联通宽带用户体验明显 |
| AS4837 | 联通普通国际线路，比 9929 便宜，晚高峰会有波动 |
| CMI | 移动国际出口，移动宽带用户直连时体验好 |
| 原生 IP | IP 归属地就是机房所在地，不被流媒体、电商平台判定为代理，注册和登录成功率高 |
| 双 ISP / 住宅 IP | IP 挂在家宽运营商名下，平台风控眼里更像真人用户，跨境电商和多账号业务常用 |

一张表能看出关键：线路决定“稳不稳”，IP 类型决定“能不能用”。只优化线路不换 IP，做跨境业务照样被拦；只有原生 IP 线路稀烂，访问体验一样难受。

**第三个数是流量。** 大带宽配小流量等于自缚手脚。1Gbps 的口子给 500G 月流量，你连一个晚上都跑不满。所以看到高带宽，第一件事是翻到流量那一栏。
